# 银行年报问答知识库

复旦大学人工智能课程 · 第一部分作业 3（方向 A）

对 10 家 A 股上市银行 2023 年年度报告做逐页解析、切块、混合检索和带出处的问答。
页面只根据检索到的年报原文回答，并在每个关键数字后标注「公司 + 年报页码」。

```bash
python scripts/download_reports.py
```

## 2. 处理流程

```
PDF
 └─ extract_reports.py   pymupdf4llm 逐页转 Markdown（表格保留行列）
     └─ build_chunks.py  按标题/段落/表格切块，写入公司、代码、年份、页码、章节
         └─ build_index.py  jieba 分词 + BM25；bge-small-zh-v1.5 向量，归一化
             └─ qa_server.py  BM25 45% + 向量 55% 混合检索，取 top-k 交给大模型
```

单公司问题会先用“指标名 + 数值”的词法规则锁定原文，再取全局 top-8；跨公司问题（含“最高/最低/排名/比较/哪些”等）按公司分别检索，每家公司取 2 个片段，避免某一家银行占满上下文。指标的同义表述（如“净息差/净利息收益率”）会一起检索。

## 3. 运行

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python scripts/download_reports.py
python scripts/extract_reports.py
python scripts/build_chunks.py
python scripts/build_index.py
uvicorn scripts.qa_server:app --host 127.0.0.1 --port 8010
```

浏览器打开 <http://127.0.0.1:8010>。

模型使用 `BAAI/bge-small-zh-v1.5`（CPU，512 维）。国内网络可先设置：

```bash
set HF_ENDPOINT=https://hf-mirror.com
```

## 4. 评测

`eval/questions.jsonl` 含 10 个问题（8 个单公司、2 个跨公司）。
启动服务后运行：

```bash
python eval/run_eval.py
```

结果保存在 `eval/results.json`，包含每个问题的回答、引用页码、top-8 检索块和得分。
人工核对与逐题召回记录见 `eval/逐题记录.md`，汇总指标见 `eval/summary.json`。

本次结果：**10 / 10 答对**（单公司 8 / 8，跨公司 2 / 2），平均响应 **5.1 秒**，最短 3.3 秒、最长 6.9 秒。
一页纸结论见 [`eval/一页结论.pdf`](eval/一页结论.pdf)，页面截图见 [`screenshots/qa_page.png`](screenshots/qa_page.png)。

## 5. 结论与错误分析

**答得好的题**：单公司事实题。题干直接给出公司和指标（如“工商银行 2023 年不良贷款率”），词法规则能先锁定“不良贷款率 1.36%”这类原文，向量与 BM25 再补上下文，答案和页码都稳定。跨公司全景题也能一次列出 10 家公司的指标，因为检索改成“每家公司各取 2 块”，不会让某一家银行占满上下文。

**曾经翻车的地方**：

1. **分项值冒充全行值**：工行第 81 页的“个人不良贷款率 0.70%”、招行第 49 页的“小微贷款不良率 0.61%”都曾排在集团口径前面。现在的词法筛选会看匹配点前后的同一句，遇到“个人/小微/信用卡/房地产/公司贷款/县域/境外”等分项词降权，并优先“集团/全行/本行”和“主要会计数据/财务指标”所在块。
2. **公式里的 100%**：中行第 9 页“不良贷款率＝……×100%”曾被误当成指标值；现在会跳过含“计算/公式/×100/＝”的匹配。
3. **同一页多个百分比**：工行第 107 页同时有“集团不良率 1.36%”和“房地产业贷款不良率 5.37%”，现在逐个匹配、按局部上下文打分，取集团口径的那一个。
4. **PDF 汉字间夹空格**：抽取文本常出现“不 良率”“净 息 差”，匹配前会先去掉汉字之间的空白，否则会漏召回。
5. **指标同义表述**：交行、招行用“净利息收益率”而不是“净息差”，已把两种叫法放进同一组同义词。

**仍然存在的限制**：部分单公司题的引用列表会夹带少量无关页（如附注封面），虽然高分出处排在前面，页面仍应只信前几条；表格跨页时表头可能丢失，需要按页码回看原 PDF；大模型偶尔会把相邻行的数字串行，关键数字必须点开引用页复核。

**结论**：同一批财报里，“某家公司某个指标是多少”这类题最适合建库——检索能直接命中表格或段落，答案可钉到页码；“10 家公司谁最高/最低”也能做，但需要逐家公司检索并处理口径（集团/本行/分项）；真正需要微调的是“口径判断、跨年趋势解释”这类无法靠单块原文回答的问题。
